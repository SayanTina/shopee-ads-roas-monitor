# Shopee Ads Reader

Chrome extension อ่านข้อมูลโฆษณาจากหน้า Shopee Ads ที่เปิดอยู่ (ดักคำตอบ JSON ที่หน้าเว็บโหลดเอง ไม่ยิง API เพิ่ม) แล้วบันทึกเป็นไฟล์ และหน้าเว็บตรวจ ROAS สำหรับพนักงาน

## Extension
1. เปิด `chrome://extensions` → เปิด "โหมดนักพัฒนาซอฟต์แวร์" → "โหลดส่วนขยายที่แกะแล้ว" เลือกโฟลเดอร์นี้
2. เปิดหน้า Shopee Ads (รีเฟรชหนึ่งครั้งหลังติดตั้ง) เลือกช่วงวันที่ใน popup แล้วกด "ไปที่ช่วงวันที่นี้"
3. หน้ารายการกลุ่มโฆษณา ใช้ "เริ่มวนอ่านกลุ่ม" ให้เข้าอ่านรายสินค้าในแต่ละกลุ่ม (ช้าๆ ครั้งละไม่กี่แถวก่อน) จนครบทุกกลุ่มที่มีค่าโฆษณา
4. กด "บันทึกข้อมูลดิบทั้งหมดเป็น JSON" ได้ไฟล์ `ads_dump_*.json` (ใช้ปุ่ม "ล้างข้อมูลที่ดักไว้" ก่อนเปลี่ยนช่วงวันที่เพื่อไม่ให้ไฟล์ปนหลายช่วง)

ไม่มีการส่งข้อมูลออกนอกเครื่อง ข้อมูลที่ดักได้เก็บใน storage ของเบราว์เซอร์จนกว่าจะล้าง

## หน้าตรวจ ROAS (GitHub Pages, โฟลเดอร์ `docs/`)
อัปโหลด 3 ไฟล์ แล้วดู ROAS จริงของแต่ละสินค้าเทียบกับเป้า ทุกอย่างประมวลผลในเบราว์เซอร์:
1. ไฟล์ Order จาก BigSeller (`Order-SKU .xlsx`)
2. ไฟล์ Ads จาก extension (`ads_dump_*.json`)
3. ไฟล์เป้าสำหรับพนักงาน (`roas-targets-staff.json`) ขอจากผู้จัดการ หน้าจะจำไฟล์นี้ไว้ในเบราว์เซอร์

ROAS จริง = ยอดขายจากไฟล์ Order ของสินค้านั้น ÷ ค่าโฆษณาของสินค้านั้น ช่วงวันที่ของ Order และ Ads ต้องตรงกัน มีตัวเลือกรวมออเดอร์ที่ยังอยู่ระหว่างจัดส่ง (ออเดอร์ที่ยกเลิกและยังไม่ชำระไม่นับเสมอ)
